# 🎂 Cake & Chaos — A Birthday Adventure

A fun, interactive birthday surprise website made with love by **Zeba** for **Talha's** birthday. No photos, no logins, no backends — just React, CSS, SVG, emojis & love.

Enter your name, unlock the mission, then scroll through a little adventure: letter → cake → wishes → mini-games → friendship terms → finale.

## ✨ What's inside

- 🎟️ **Name Gate + Welcome Screen** — personalized invite entry
- 💌 **Birthday Letter** — envelope animation with typewriter effect
- 🎂 **Interactive Cake** — make a wish, blow out candles, take the knife & cut on the mark
- 💖 **Birthday Wishes** — tap-to-reveal wish cards
- 🎮 **Mini-Games** — compliment catcher, mystery gifts & birthday quiz
- 📜 **Friendship Terms** — funny non-negotiable conditions
- 🎉 **Final Surprise** — confetti, fireworks & celebration
- 🎨 **4 Themes** — sky, pink, mint & midnight + starfield background with music/sound effects

## 🛠️ Built with

React 19 + Vite, `canvas-confetti`, `lucide-react`, plain CSS (no UI framework).

## 🚀 Run it

```bash
npm install
npm run dev
npm run build
```

Open the `dev` URL, type the birthday star's name, and enjoy the mission! 🎉
